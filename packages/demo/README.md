# @math-assistant/demo

Typed demo data and UI building blocks for landing page product previews.

See [docs/demo-components.md](../../docs/demo-components.md) for architecture and usage guidelines.

## Quick start

```bash
npm install
npm test
```

## Exports

- `@math-assistant/demo` — components, data, hooks
- `@math-assistant/demo/data` — fixtures only
- `@math-assistant/demo/components` — `DemoFrame`, `DemoSection`, `DemoCard`
- `@math-assistant/demo/hooks` — animation helpers
